# M0G3507 MEMS陀螺仪 + TI MCU（UART PA23/PA24）集成说明

## 1. 项目目标

使用 TI MSPM0 系列 MCU，通过 UART（PA23 / PA24）读取 M0G3507 MEMS
陀螺仪模组数据，实现：

-   实时读取 Z 轴角速度（°/s）
-   实时读取航向角 Yaw（°）
-   用于姿态角解算或直接上位机显示

------------------------------------------------------------------------

## 2. 硬件信息

### 2.1 陀螺仪模块（M0G3507）

核心特性：

-   MCU：MSPM0G3507
-   内置 Kalman 滤波姿态解算
-   输出：Z轴角速度 + Yaw角
-   UART 直接输出结果（无需用户二次解算）
-   最高输出刷新率：1000Hz
-   波特率：4800 \~ 230400 bps 可配置

------------------------------------------------------------------------

### 2.2 引脚定义

  引脚   名称       说明
  ------ ---------- -------------
  VCC    电源       3.3V \~ 16V
  RX     串口输入   MCU TX
  TX     串口输出   MCU RX
  GND    地         共地

------------------------------------------------------------------------

### 2.3 TI MCU 接线

  陀螺仪   TI MCU
  -------- ----------------
  TX       PA24 (UART_RX)
  RX       PA23 (UART_TX)
  GND      GND
  VCC      5V

------------------------------------------------------------------------

## 3. UART协议

### 3.1 数据帧

角速度： 0x5A 0xAA AzL AzH SUM

航向角： 0x5A 0xBB YawL YawH SUM

------------------------------------------------------------------------

### 3.2 数据解析

DATA = (int16_t)((DATAH \<\< 8) \| DATAL)

------------------------------------------------------------------------

### 3.3 物理量

Wz = ((AzH\<\<8)\|AzL) / 32768 \* 2000 °/s\
Yaw = ((YawH\<\<8)\|YawL) / 32768 \* 180 °

------------------------------------------------------------------------

### 3.4 校验

SUM = 0x5A + TYPE + DL + DH (取低8位)

------------------------------------------------------------------------

## 4. MCU解析建议

状态机：

WAIT 0x5A → TYPE → DL → DH → SUM

------------------------------------------------------------------------

## 5. 示例代码

``` c
int16_t data = (int16_t)((dh << 8) | dl);

if(type == 0xAA) wz = data / 32768.0f * 2000.0f;
if(type == 0xBB) yaw = data / 32768.0f * 180.0f;
```

------------------------------------------------------------------------

## 6. 配置指令

解锁： 55 AA 13 8E 5F

波特率： 55 AA 03 06 00

输出速率： 55 AA 02 0A 00

保存： 55 AA 00 00 00

Yaw清零： 55 AA 15 00 00

------------------------------------------------------------------------

本模块已完成姿态解算，MCU只需UART解析即可。
